# WinIsland Plugin Marketplace

This repository is the curated source registry for the WinIsland plugin market.
Plugin binaries stay in each author's public GitHub repository. The registry
validates the source repository, license, release package, build provenance,
manifest metadata, and package hash before publishing a signed catalog.

## Add a plugin

1. Keep the plugin source in a public GitHub repository with a detected
   open-source license.
2. Publish the plugin through the reusable WinIsland build workflow.
3. Add one `plugins/<plugin-id>.toml` file in a pull request.
4. Wait for the automated checks and maintainer review.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the complete format and release setup.

## Trust model

- Registry pull requests only register source repositories.
- Release URLs, metadata, and SHA-256 values are generated by automation.
- Accepted packages must have GitHub build provenance from the official reusable
  workflow.
- WinIsland verifies the signed catalog and the complete downloaded ZIP before
  using its existing package validation and transactional installer.
- Plugins are native in-process DLLs and are not sandboxed. Inclusion is not a
  guarantee that a plugin is harmless.

## Published catalog

The latest signed catalog is published in the `catalog-v1` GitHub Release:

- `catalog-v1.json`
- `catalog-v1.sig`
- content-addressed plugin icons
